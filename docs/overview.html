Product Principles

4 本柱

出典: vision.md

1

一人〜少人数の管理に特化

設定・概念を最小限に。導入即日で使える。1 人でも価値があり、人が増えても破綻しない。「管理のための管理」を作らない。

2

マルチタスクを捌く

複数プロジェクト・複数文脈を同時に見渡す（今日 / 今後 / プロジェクト別 / カレンダー）。「次に何をやるか」を即決できる。

3

徹底したコミットメントの可視化

タスクを「やること」でなく 約束として扱う（誰が・何を・いつまでに）。進捗・猶予・遅延リスクを常時可視化。目的は監視でなく安心。

4

AI との能動的協働 →（北極星）AI 社員のマネジメント

AI を「聞けば答える」から「先回りして整え・提案する」へ。最終形はミッションを与えて自律実行、必要時だけユーザーへ Post。主導権は常に人間。

ADR-0001: コミットメントを第一級エンティティとして表現する

承認  2026-06-19 ・ Q-PROD-2 ・ 全文を読む

案A（Task 属性拡張）／案B（別エンティティ）／案C（ハイブリッド）を検討し、案B を採用。「一人ではやり切れない規模＝1 約束が複数作業に枝分かれ」を直接体現するため。案A は現状行動への最適化で、プロダクトが拡張しようとする世界を自己否定するため不採用。

  • 両立条件：リッチ項目はスキーマに持つが UI は段階開示・原則任意。単独ユーザーは今と同じ軽さ。
  • シーケンス：M4（構造検証・AI 非依存）→ M3（AI 充填）の順。構造を確かめてから AI を乗せる。
  • 移行：done:boolean → status、tascal.v1 → v2（1:1 変換）。
Data Model

データモデル

出典: data-model.md（🟡 提案段階）

Commitment ✅ 第一級

= 約束。1 つの Commitment が複数 Task を束ねる。

// owner/stakeholder/softDue は任意・段階開示
Commitment {
  id, projectId, title,
  status: 'todo'|'doing'|'done'|'blocked',
  priority,
  due,           // 確定締切。当面これ1本
  softDue?,      // 努力目標（任意）
  ownerId?,      // 担当者（任意・単独=自分）
  ownerType?,    // 'human'|'ai'（AI 着手時）
  stakeholder?,  // 約束の相手（任意）
  source?        // 'manual'|'ai'|'integration'
  // riskLevel は持たない = 派生算出
}

Task

= 作業の単位。Commitment にぶら下がる（1:1 最頻、分割時 1:N）。

Task {
  id, commitmentId,
  title, notes,
  status: 'todo'|'doing'|'done'|'blocked',
  subs: Subtask[],
  createdAt, updatedAt
}

// 既存タスク = Commitment 1件 + Task 1件 に変換
⚑
保存と派生の分離（CLAUDE.md 原則）：遅延（late）は status に入れず、due 超過かつ未完を毎回派生算出（当日依存のため保存しない）。締切ラベル・達成率・遅延リスクも selectors 側で計算する。
AI Collaboration

AI 協働の設計

出典: ai-collaboration.md（🟡 提案 / 当面保留）

能動性

聞かれる前に整える。ただし割り込まず、提案はインボックスにそっと溜める。

人間が主導

既定は「提案 → 人が承認 → 実行」。自動実行は明示許可の範囲のみ。

透明性

根拠と実行を ActivityLog に記録。取り消し可能に。

最小権限・安全第一

破壊的操作は自動化しない。API キーはクライアントに出さない。

Architecture

技術アーキテクチャ

出典: architecture.md / CLAUDE.md

✅ 決定  シェル戦略

デスクトップ = Electron（Tauri 不採用）。Web は同じ React 資産。Node メインプロセスを「ローカルの安全な実行層」に使える。モバイルは将来 Swift / Capacitor で別系統。

🟡 現フェーズ  データ基盤

当面ローカル継続（localStorage → 将来ローカル DB）。BaaS / 自前 API は Web 展開検討時に判断。共有・ホスト型 AI はそれまで保留。

確定の技術土台

pnpm（版固定・Corepack）／ Node LTS（.nvmrc）／ Vite + React 18 + TypeScript（strict）／ React Context ＋ selectors ／ 素の CSS + デザイントークン。

テスト・CI・セキュリティ

Vitest（純粋ロジック）＋ Playwright（主要フロー）。CI は frozen-lockfile → build。AI / 外部キーはクライアント・リポジトリに置かない。
